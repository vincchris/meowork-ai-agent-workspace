MVP runs in-memory with identical shapes.## AI providersDefault: **Qwen** (`QWEN_API_KEY`, OpenAI-compatible). Without a key, the deterministic offline provider runs the full loop (plan → tools → review → costs) so the office is always demoable. Add DeepSeek/Kimi/GLM/local Ollama via `OPENAI_COMPAT_*` or `lib/providers.ts`.## Safety- LOW tools auto-run; MEDIUM/HIGH require **Allow once / Deny**- Sandbox `workspace/sandbox`, path-escape checks, command allowlist, per-task/daily/monthly caps (warn 80%, pause 100%)- Scoped memory: agents see only their subtask brief + parent title## MVP scope (Phase 1 ✅)Virtual office · 5 agents (Yuki + 4 specialists) · task/subtask engine · 1 provider (+mock) · real file/web tools · token+cost tracking · activity log · approvals · budgets · theme switcher
